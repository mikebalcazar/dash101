# Capturas

Faltan. El chat no las puede tomar: el proxy de salida rechaza `*.netlify.app`,
así que nadie aquí ha visto el portal corriendo. Las toma Mike.

## Cómo

- **1600 px de ancho**, tema claro, PNG.
- **Todo inventado.** Nombres de cliente, montos, fechas y referencias de pago.
  Ni un cliente real de Taller 101 en una captura que va a acabar en una
  presentación. Lo más limpio es activar un cliente de prueba con un proyecto
  armado a propósito y capturar eso.
- Un cliente con dos proyectos y tres o cuatro muebles se ve mejor que uno con un
  solo renglón.
- Que los muebles estén en etapas distintas: si todos van en la misma, la barra
  de avance no se entiende.
- Que quede saldo pendiente. Un estado de cuenta en ceros no explica para qué
  sirve la pantalla.
